<!-- ABOUT -->
## Info

The following locomotives had their controls changed:
* DE2
  * Throttle, independent brake, train brake.
* DH4
  * Throttle, independent brake, train brake, dynamic brake.
* DM3
  * Throttle, independent brake, train brake, engine brake.
* DM1U
  * Train brake.
